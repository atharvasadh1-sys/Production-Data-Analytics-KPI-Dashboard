# Production Data Analytics & KPI Dashboard

A Python-based production analytics project that processes machine, operator, and material-flow data to generate KPIs, exception reports, management insights, and visual dashboards.

## Key Features

- Production data cleaning and validation
- Machine downtime and utilization analysis
- Operator availability and shortage analysis
- Material flow and interruption analysis
- Shift-wise KPI calculation
- Exception and productivity-loss reporting
- Excel-based dashboard and visualizations
- AI-assisted analysis and prompt-based workflow

## Technologies

- Python
- Pandas
- NumPy
- OpenPyXL
- Microsoft Excel
- Data Analysis & Visualization
- AI Prompting

## Project Workflow

1. Raw production data is processed and validated.
2. Invalid, duplicate, and noise events are handled.
3. Machine, operator, and material-flow KPIs are calculated.
4. Exceptions and productivity-loss events are identified.
5. Results are exported to Excel.
6. Dashboards and visualizations are generated for analysis.

## Files

- `script1_data_processing.py` – Data cleaning and preprocessing
- `script2_kpi_engine.py` – KPI calculations and analysis
- `script3_final_compliance.py` – Final workbook, dashboard and visualization generation
- `kpi_output_script2_final.xlsx` – Final analytical output

## How to Run

Install dependencies:

```bash
pip install pandas numpy openpyxl
```
